# Aron Sabu Abraham — Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

The site is a responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript. The portrait and résumé are included in `assets/`.

## Customize
- Replace `assets/aron-profile.jpg` to change the portrait.
- Replace `assets/Aron-Sabu-Abraham-Resume.pdf` to update the résumé.
- Edit `index.html` to update text, links, skills or projects.

Fonts are loaded from Google Fonts; an internet connection is needed for those fonts. The site itself works locally without a build step.
